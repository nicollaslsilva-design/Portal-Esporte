# Portal-Esporte
ATIVIDADE PRÁTICA — HTML + CSS BÁSICO

Desenvolvimento de um Portal Temático
Cada aluno deverá desenvolver o tema sorteado ao final deste documento.
OBJETIVO: criar uma página utilizando HTML semântico e CSS básico, aplicando seletores, cores,
fontes, espaçamentos, bordas e efeitos de hover. O conteúdo e a identidade visual devem ser adaptados
ao tema individual sorteado.

1. Estrutura do projeto
 Crie uma pasta para o projeto.
 Dentro dela, crie obrigatoriamente os arquivos index.html e style.css.
 O arquivo style.css deverá ser conectado ao HTML por meio da tag <link>.
<link rel="stylesheet" href="style.css">
2. Estrutura HTML obrigatória
Utilize corretamente os seguintes elementos semânticos:
 <header>
 <nav>
 <main>
 <section>
 <article>
 <aside>
 <footer>

3. Cabeçalho e navegação
 No <header>, coloque o nome do portal e uma pequena descrição relacionada ao tema sorteado.
 No <nav>, crie pelo menos 4 links, por exemplo: Início, Conteúdos, Sobre e Contato.
 Os links podem utilizar href="#".

4. Conteúdo principal
Dentro do <main>, crie uma <section> principal contendo pelo menos 4 <article> relacionados ao seu tema.
 Cada artigo deverá possuir um título.
 Cada artigo deverá possuir uma pequena descrição.
 Inclua pelo menos duas informações adicionais coerentes com o tema, como categoria, nível, data,
preço, classificação, duração, localização ou outra informação pertinente.

Atividade prática — HTML + CSS Básico

5. Área complementar
 Crie um <aside> com uma lista de pelo menos 5 itens relacionados ao tema do portal.
 O conteúdo do aside deve ser diferente do conteúdo principal.

6. CSS básico obrigatório
Todo o CSS deverá ficar no arquivo style.css
 No body: cor de fundo, fonte e margin: 0.
 No header: background-color, color, padding e text-align.
 No nav e nos links: cores, espaçamento e remoção do sublinhado.
 Utilize :hover nos links do menu.
 No main: background-color, margin e padding.
 Nos article: background-color, margin, padding, border e border-radius.
 No aside: cor de fundo, margin, padding e border-radius.
 No footer: cor de fundo, cor do texto, padding e texto centralizado.

7. Desafios
DESAFIO 1 — PERSONALIZAÇÃO
Seu site não poderá utilizar exatamente as mesmas cores usadas pelo professor. Crie uma identidade visual
própria e coerente com o seu tema.
DESAFIO 2 — HOVER NOS CARDS
Crie um efeito utilizando :hover também nos <article>. Exemplo:
article:hover {
background-color: white;
}
DESAFIO 3 — CLASSE DE DESTAQUE
Escolha um dos artigos e atribua a ele a classe destaque. Crie no CSS uma regra .destaque que o diferencie
visualmente dos demais.
<article class="destaque">
.destaque {
border: 3px solid;
}
DESAFIO 4 — SEÇÃO EXTRA
Adicione uma nova seção de destaque relacionada ao tema sorteado e aplique uma estilização diferente das
demais áreas da página.

8. Regras
 Não utilizar Bootstrap, Tailwind ou outros frameworks CSS.
 Não utilizar templates prontos.
 Não utilizar Flexbox ou Grid nesta atividade.
 Utilizar somente os recursos de HTML e CSS trabalhados até o momento.

Atividade prática — HTML + CSS Básico

 Cada aluno deverá desenvolver exclusivamente o tema sorteado na tabela ao final.
 Conteúdo, textos, cores e identidade visual devem ser adaptados ao tema recebido.
